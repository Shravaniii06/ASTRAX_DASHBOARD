# ASTRA-X: Autonomous AI-Enabled CubeSat Platform

ASTRA-X is a low-cost CubeSat health-management prototype developed for Smart India Hackathon.

## Key Features

- ESP32-based flight-controller simulation
- Real-time temperature, voltage, current, IMU and light telemetry
- Health-score based anomaly detection
- Autonomous Normal, Warning, Critical and Safe Modes
- Smart power management and load shedding
- Priority-based LoRa telemetry
- SD card store-and-forward data backup
- Live mission-control dashboard
- Digital Twin visualization
- Fault injection demo panel

## Technology Stack

### Frontend
- React
- Vite
- Recharts
- Lucide React

### Backend
- Node.js
- Express.js
- Firebase Realtime Database
- REST API

## Run Locally

### Backend

```bash
cd Backend
npm install
npm run dev
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

Open:

```text
http://localhost:5174
```
